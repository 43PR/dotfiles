### Что это?

Это полноценная настраиваемая среда рабочего стола для Linux (панель, меню приложений, настройки, выбор обоев, экран блокировки, меню питания и т. д.). Она построена на **Hyprland** (оконный менеджер) и **Quickshell** (с его помощью создаются панель и меню).

### Что нужно для запуска?

- **Дистрибутив Linux на основе Arch**: Arch, CachyOS, EndeavourOS, Manjaro и т. д.
- В основном **чистая установка системы**. Существующие конфигурации, которые будут заменены, автоматически сохраняются в резервную копию.

Новичкам рекомендую CachyOS: https://youtu.be/eo9MejbzWto

Раздел о настройке в видео можно пропустить, теперь он автоматизирован. Просто выполните команду установки.

### Сложно ли этим пользоваться?

Не очень. Почти всё делается сочетаниями клавиш, есть и альтернативы для мыши:

- `Super + I` открывает настройки - щелчок средней кнопкой мыши по часам

Полный список находится в разделе [Сочетания клавиш](#сочетания-клавиш). Также можно навести курсор на элементы панели, чтобы увидеть их действия, а щелчком правой кнопки по часам открыть настройки панели.

### Что нужно знать перед установкой?

- После завершения установщика выйдите из системы и войдите снова.
- Обои не входят в установку. Скачайте их и поместите в `Pictures/Wallpapers`.

Заходите в [Discord](https://discord.gg/HQwU9SzHj).

## Возможности

- **Быстрый и лёгкий Quickshell** — Оптимизированные компоненты рабочего стола, которые работают быстро и легко настраиваются.
- **Верхняя панель** — Настраиваемая панель с меню настроек и быстрыми ярлыками.
- **Настройки** — Система, сеть, bluetooth, дисплей, звук, хранилище, темы и многое другое.
- **Выбор обоев и динамические цвета** — Собственный выбор обоев с автоматической генерацией цветов на основе обоев.
- **Готовые темы** — Monochrome, Nord, Tokyo Night и другие популярные, с возможностью создавать свои.
- **Меню приложений** — Поиск приложений через **Rofi**, история буфера обмена и управление прозрачностью.
- **Zsh + Starship** — Настраиваемая оболочка с автоподсказками и историей.
- **Заметки и напоминания** — Быстрые заметки, задачи и напоминания.
- **Меню питания** — Настраиваемое меню питания.
- **Hyprlock** — Собственный экран блокировки.
- **Spotify + Spicetify** — Собственная тема на основе **text - darkthemer** (изменённая).

> Все программы: [packages.txt](../packages.txt)

## Сочетания клавиш

Щёлкните правой кнопкой мыши по часам, чтобы открыть настройки панели. Наведите курсор на элементы, чтобы увидеть их действия. Чтобы закрыть компоненты, нажмите Esc или то же сочетание клавиш.

| Сочетание | Действие |
| --- | --- |
| `Super + T` | Терминал |
| `Super + Q` | Закрыть активное окно |
| `Super + D` | Меню приложений |
| `Super + Space` | Переключить плавающее окно |
| `Super + F` | Переключить полноэкранный режим |
| `Super + 1, 2, 3..` | Сменить рабочее пространство |
| `Super + Shift + 1, 2..` | Переместить окно на рабочее пространство |
| `Super + E` | Файловый менеджер |
| `Super + B` | Браузер |
| `Super + V` | История буфера обмена |
| `Super + I` | Меню настроек |
| `Super + S` | Быстрые действия |
| `Super + O` | Переключить прозрачность |
| `Super + C` | Заметки и напоминания |
| `Super + W` | Выбор обоев |
| `Super + Shift + C` | Пипетка (выбор цвета) |
| `Super + Колесо мыши` | Увеличить/уменьшить масштаб |
| `Super + Shift + W` | Показать/скрыть панель |
| `Super + Grave` | Меню выхода |
| `Super + Tab` | Заблокировать экран |
| `Super + N` | Уведомления |
| `Super + R` | Включить/выключить запись экрана |
| `Delete` | Скриншот всего экрана |
| `SHIFT + Delete` | Скриншот выбранной области |

> [!note]
>
> Перемещайте и изменяйте размер окон с помощью Super + перетаскивание левой/правой кнопкой мыши.
>
> Все сочетания клавиш: [.config/hypr/keybinds.lua](../.config/hypr/keybinds.lua)

## Установка

**ПРОЧИТАЙТЕ ВСЁ**

Работает на Arch, CachyOS, EndeavourOS, Manjaro и т. д.

В первую очередь предназначено для чистой установки (существующие файлы конфигурации, которые будут заменены, автоматически сохраняются в резервную копию).

**Сначала установите git, затем выполните следующую команду и продолжайте установку до её завершения**

```bash
sudo pacman -S git
```

```bash
git clone https://github.com/43PR/dotfiles.git
cd dotfiles
chmod +x install.sh
./install.sh
```

После завершения установки выйдите из системы и войдите снова.

Скачайте обои и переместите их в Pictures/Wallpapers. Выбор обоев: Super + W.

> [!important]
> **Не перемещайте и не удаляйте репозиторий dotfiles после установки.**
>
> В этой конфигурации используются **символические ссылки (симлинки)**, указывающие на файлы внутри клонированного репозитория. Если вы переместите или удалите репозиторий, эти ссылки перестанут работать.
>
> Если вы переместили репозиторий, просто выполните:
>
> ```bash
> ./install.sh
> ```
>
> Установщик автоматически обновит существующие симлинки, чтобы они указывали на новое расположение.

## Обновление

Если вы не перемещали папку репозитория/dotfiles, выполните:

```bash
cd dotfiles
git pull
./update.sh
```

Другие параметры: `--dry-run` (предварительный просмотр изменений), `--skip-packages`, `--skip-theme`.

Dotfiles подключены через симлинки, поэтому `git pull` напрямую обновляет ваши рабочие конфигурации.

В конце выполнения можно ознакомиться с выведенными напоминаниями.

> [!tip]
> Если после pull изменились файлы Quickshell (`.qml`), выполните:
>
> ```bash
> ./update.sh --restart-shell
> ```
>
> чтобы автоматически перезапустить Quickshell.
