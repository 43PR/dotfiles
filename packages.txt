# Bar: CPU / GPU Stats & Temperatures
# --------------------------------------------------
# The bar's GPU/temp probe is vendor-agnostic and degrades gracefully:
#   CPU temp   -> `sensors` (lm_sensors)
#   AMD GPU    -> sysfs (gpu_busy_percent + hwmon), nothing extra needed
#   Intel GPU  -> sysfs clock estimate, nothing extra needed
#   NVIDIA GPU -> nvidia-smi (nvidia-utils)
# Uncomment ONLY what matches your hardware:

lm_sensors               # `sensors` for CPU temp / GPU temp fallback
# nvidia-utils           # NVIDIA: provides nvidia-smi (usage + temp)
# intel-gpu-tools        # Intel: optional, intel_gpu_top for real usage % (needs CAP_PERFMON/root)
